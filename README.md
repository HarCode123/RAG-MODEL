# BIORAG
So this is my first attempt to try building and developing the RAG Model with simple stacks and work on multiple files
As RAG is used for retrieving the data and information from the files and generate curated answers with the collected facts according to the users questions and tasks , it handles it with thorough training and utmost precision to give the full outcomes of what it is expected by us , and also removing the main drawbacks in the answer retrieval--HALLUCINATIONS

So for this project I am trying to make use of the Biology notes of Class XI and Class XII where for school students who wished to prepare for NEET , they can use this application to ask questions and verify their doubts while also providing summary of the lessons.
